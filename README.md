

# 📱 ESPRIT Mobile App

Une application Android moderne développée avec **Jetpack Compose** et **MVVM**, répliquant les principales fonctionnalités du portail universitaire **ESPRIT**.

---

## 🚀 Fonctionnalités principales

- 🔐 **Authentification** (Login via NestJS backend)
- 🎓 **Espace Étudiant** : emploi du temps, absences, examens, résultats
- 🧑‍🏫 **Espace Enseignant**
- 👨‍👩‍👧 **Espace Parent**
- 🏛️ **Espace Admin** : gestion des annonces, stages, événements, utilisateurs
- 🗞️ **Annonces & Communication interne**
- 👤 **Profil utilisateur** + changement de mot de passe sécurisé
- 💾 **JWT persistant via DataStore**
